# Elliot MCP v0.7.2 — listable on the GitHub Marketplace

GitHub refuses a Marketplace listing whose Action description reaches 125 characters. v0.7.1's was 160, so the listing was rejected at validation.

## Fixed

- The Action description is now 108 characters: "Checks every claim in a pull request description against the code, with file:line proof. Can block the merge."
- `test/action-metadata.test.js` enforces GitHub's real limit (under 125 characters) instead of a guessed one, so a description that cannot be listed fails the build.

## Upgrade

```yaml
- uses: EmanueleCell4/elliot-mcp@v0.7.2
  with:
    mode: strict
    anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
```

Nothing else changed since v0.7.1.

## Verification

`npm ci`, `npm run check`, `npm test` on Node 20 or newer. 48 tests pass.
