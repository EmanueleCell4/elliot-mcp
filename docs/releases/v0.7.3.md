# Elliot MCP v0.7.3 — the README is back

v0.7.2 shipped with `README.md` and `examples/workflows/elliot-strict.yml` truncated to zero bytes. The repository front page rendered empty, the copy-paste workflow was an empty file, and the build stayed green through all of it. Anyone who opened the repository between v0.7.2 and this release saw nothing.

## Fixed

- `README.md` is restored in full (26,760 bytes), and `examples/workflows/elliot-strict.yml` is a complete workflow again.
- Both now point at `EmanueleCell4/elliot-mcp@v0.7.3` instead of a stale tag.
- `test/repo-content.test.js` fails the build when `README.md`, `LICENSE` or `action.yml` is missing or truncated, when an example workflow is not a complete workflow (`name:`, `on:`, `jobs:`), or when either points at a version other than the one in `package.json`. The three checks that matter fail on the v0.7.2 tree and pass on this one.

Nothing in the MCP server, the Action or the strict gate changed. v0.7.2 runs correctly; only its documentation was empty.

## Upgrade

```yaml
- uses: EmanueleCell4/elliot-mcp@v0.7.3
  with:
    mode: strict
    anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
```

## Verification

`npm ci`, `npm run check`, `npm test` on Node 20 or newer. 55 tests, 53 pass, 2 skipped, 0 fail.
