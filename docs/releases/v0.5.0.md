# Elliot MCP v0.5.0 — Independent AI verification

This release includes the validated changes merged into main after v0.4.0.

## New capabilities
- Functional outcome checks: verify_outcome runs a specified validation command in a temporary repository copy using an OS-level sandbox with network disabled. Only a zero exit code yields VERIFIED; if isolation cannot start, returns INCONCLUSIVE without executing the command.
- Reviewer separation: distinct auditor and reviewer MCP server modes, audit-scoped reviewer credentials, and restricted reviewer tool exposure.
- Ed25519 attestations: optional signing using a private key outside the repository; verification against an independently trusted public key.
- Reproducible demo: npm run demo reproduces a privacy claim contradicted by code.
- CI: Node.js 20/22 on Linux/macOS, automated tests, static checks and dependency audit.

## Verification
Run npm ci, npm run check, npm test, and npm run demo on Node 20+.

Install directly from GitHub: npx -y github:EmanueleCell4/elliot-mcp#v0.5.0 init

## Limitations
- OS sandbox network/filesystem/process isolation must be validated in the intended deployment environment.
- Reviewer MCP permissions do not independently enforce OS-level process isolation.
- A signature alone does not establish signer identity; trust must be established independently.
- This release is NOT certified production-ready.

## Distribution
This GitHub source release does not publish elliot-mcp@0.5.0 on npm or update the official MCP registry. Use the GitHub source installation command until npm publication is separately confirmed.
