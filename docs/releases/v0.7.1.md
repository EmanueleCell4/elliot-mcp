# Elliot MCP v0.7.1 — the Action loads again

`action.yml` was not valid YAML, so `uses: EmanueleCell4/elliot-mcp@v0.7.0` failed to parse before the Action ran. Two description fields contained an unquoted `": "`, which YAML reads as the start of a new key. Every release up to and including v0.7.0 carries the same defect.

## Fixed

- `action.yml` parses. The two descriptions are quoted, and the Action's name and description now say what it does rather than naming the tool.
- New tests (`test/action-metadata.test.js`) load `action.yml` and fail the build on an unquoted `": "`, a missing or over-long name or description, a missing or invalid `branding` colour, an undeclared input, or a default that is not the non-blocking `report` mode. They fail on the v0.7.0 file and pass on this one.

## Upgrade

```yaml
- uses: EmanueleCell4/elliot-mcp@v0.7.1
  with:
    mode: strict
    anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
```

Nothing else changed: the strict gate, the Codex integration and the MCP server are the same as v0.7.0.

## Verification

`npm ci`, `npm run check`, `npm test` on Node 20 or newer. 48 tests pass.
