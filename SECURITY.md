# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub's private vulnerability reporting ("Report a vulnerability" in the Security tab of this repository), or by email to cellaemanuele05@gmail.com with "Elliot security" in the subject.

Please include what you found, how to reproduce it, and the version or commit you tested.

## What to expect

- Acknowledgement within 72 hours.
- An assessment and a planned fix date within 7 days.
- Credit in the release notes, if you want it.

## Scope

In scope: the `elliot-mcp` package, the MCP server, the GitHub Action, the sandbox used by `verify_outcome`, and receipt signing and verification.

Security lead: Emanuele Cella (maintainer).

## Supported versions

Only the latest release receives security fixes.
